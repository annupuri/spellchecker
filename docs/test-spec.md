# 動作仕様チェックリスト

CLI が満たすべき挙動の一覧。

- 引数なしで実行した場合、実行例 (usage) を表示して終了すること。 ⇒ OK

- 引数を 1 つ以上指定した場合、辞書をロードすること。 ⇒ OK
  - 実行ファイルと同じディレクトリに辞書 (`words`) がある場合、それを読み込むこと。 ⇒ OK
  - 同じディレクトリに辞書 (`words`) がない場合、内蔵の辞書を読み込むこと。 ⇒ OK

- 引数を 1 つ指定した場合、それがファイルなら、そのファイルの中に書かれているキーワードで辞書を検索すること。 ⇒ OK
  - キーワードファイルのサイズが実行マシンのメモリサイズを超えていても、`OutOfMemoryError` が発生しないこと。 ⇒ OK

- 引数を 2 つ以上指定した場合、それらをキーワードとみなして辞書を検索すること。 ⇒ OK

> 巨大なキーワードファイルの生成には [`InputFileCreater`](../src/test/java/io/github/annupuri/spellchecker/InputFileCreater.java) を使用できます。
